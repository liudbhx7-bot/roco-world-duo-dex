# 1.5 验证记录

验证对象为 1.5（构建 6）。发布附件是待签名 IPA，真机覆盖安装使用相同版本的开发签名包。

| 环境 | 已核实的项目 |
| --- | --- |
| iPhone 模拟器 | 16 项自动测试通过，覆盖图鉴加载、形态区分、技能与属性图标、地图引用、立绘匹配、水蓝蓝动画、音频解码、播放和停止。 |
| iPhone Duo 展开与合拢模拟器 | 两种状态各通过 13 项界面测试，覆盖查编号、同编号形态切换、技能搜索与详情、地图交互、008 与 496 的相册识别，以及无匹配照片重新框选。增大触控区域后，两种状态又分别复测资料、技能和地图。 |
| 减弱动态效果 | 对同一幅静态立绘连续取帧。开启系统设置后，画面中的立绘停止上下浮动。 |
| iPhone Duo 真机 | 确认覆盖安装后系统显示版本 1.5、构建 6，并核对发现记录和播报设置。此次安装时手机锁屏，前台启动、实拍识别及扬声器听感仍待本版真机验证。 |

图鉴的技能测试包含咔咔壳的「肥皂泡」，核对了水系魔攻、自学 Lv.1、威力 60 和能耗 1。识别测试检查已知立绘、近似形态的候选与无关图像；拍摄游戏屏幕时的反光、角度和主体大小都会影响结果。
